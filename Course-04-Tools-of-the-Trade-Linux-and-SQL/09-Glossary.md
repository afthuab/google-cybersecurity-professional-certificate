# Course 4 – Linux and SQL Glossary

| Term | Meaning |
|---|---|
| Absolute file path | A complete path starting from the root directory (`/`), such as `/var/log/auth.log` |
| Bash | Bourne Again Shell; a widely used command-line interpreter on Linux systems |
| `chmod` | Linux command used to change read, write, and execute permissions on files and directories |
| `chown` | Linux command used to change the user and/or group ownership of a file or directory |
| CLI | Command-Line Interface; a text-based interface used to run commands in a shell or terminal |
| Database | An organized collection of structured data stored electronically for querying and management |
| Foreign key | A column in one database table that references the primary key in another table |
| FHS | Filesystem Hierarchy Standard; defines standard directory layout in Linux (`/`, `/etc`, `/var`, `/home`) |
| `grep` | Linux command-line utility that searches text or files for lines matching a pattern |
| GUI | Graphical User Interface; a visual interface using windows, icons, and menus |
| Kernel | The core component of an operating system that manages hardware, memory, and processes |
| Linux distribution | A packaged operating system built around the Linux kernel with utilities and a package manager |
| `man` page | Built-in manual documentation accessed from the Linux terminal using `man <command>` |
| Operating system (OS) | System software that manages hardware resources and provides services for applications |
| Pipe (`|`) | Shell operator that sends the standard output of one command as standard input to another |
| Primary key | A column (or combination of columns) that uniquely identifies every row in a database table |
| Relational database | A database that organizes information into tables with rows and columns linked by keys |
| Relative file path | A path interpreted relative to the user's current working directory |
| Root user | The administrative superuser account on Linux with unrestricted system privileges |
| Shell | A program that interprets user commands and communicates with the operating system kernel |
| SQL | Structured Query Language; used to query, filter, and manage data in relational databases |
| SQL `JOIN` | A clause that combines rows from two or more tables based on a related column |
| Standard error (`stderr`) | Output stream used by commands to display error messages |
| Standard input (`stdin`) | Input stream read by a command, typically from the keyboard or a pipe |
| Standard output (`stdout`) | Default output stream where a command writes normal results |
| `sudo` | Command that permits authorized users to execute specific tasks with elevated privileges |
