# Course 02 – Play It Safe: Manage Security Risks

## Course overview

This course looks at how organizations identify and manage security risks. It covers security domains, threats and vulnerabilities, frameworks and controls, security audits, SIEM tools, and incident response playbooks.

## What I learned

- Identify threats, risks, and vulnerabilities that can affect business operations.
- Understand how security frameworks and controls help reduce risk.
- Apply the CIA triad to workplace situations.
- Understand the NIST Cybersecurity Framework and Risk Management Framework.
- Understand the purpose of SIEM dashboards and security logs.
- Use an incident response playbook to guide an investigation.
- Plan and document a basic security audit.

## Course modules

1. **Security domains** – CISSP domains, threats, risks, vulnerabilities, and NIST RMF.
2. **Security frameworks and controls** – CIA triad, NIST CSF, OWASP principles, and security audits.
3. **Introduction to cybersecurity tools** – Logs, SIEM platforms, dashboards, and alert monitoring.
4. **Use playbooks to respond to incidents** – Incident response phases and playbook-based actions.
