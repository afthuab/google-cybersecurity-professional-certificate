# Course 2 – Cybersecurity Glossary

| Term | Meaning |
|---|---|
| Asset | Something valuable that an organization needs to protect |
| Audit | A review of processes, systems, or controls against defined requirements |
| CIA triad | Confidentiality, Integrity, and Availability |
| Control | A safeguard used to manage security risk |
| Corrective control | A control that helps fix a problem or restore normal operation |
| Detective control | A control that identifies suspicious activity or incidents |
| Framework | A structured set of guidance for managing cybersecurity |
| Impact | The consequence if a risk event occurs |
| Incident response | The process of handling and recovering from security incidents |
| Likelihood | An estimate of how likely an event is to occur |
| NIST CSF | NIST Cybersecurity Framework |
| NIST RMF | NIST Risk Management Framework |
| OWASP | Open Worldwide Application Security Project |
| Playbook | Documented steps for handling a specific situation or incident |
| Preventive control | A control intended to prevent or reduce the chance of an incident |
| Risk | The possibility of loss or harm when a threat affects an asset |
| Risk assessment | The process of analysing and evaluating risk |
| Security audit | A review of security practices and controls |
| SIEM | Security Information and Event Management |
| Threat | A possible cause of harm to an asset |
| Vulnerability | A weakness that could be exploited |
