# Course 1 – Foundations of Cybersecurity

This course introduced the cybersecurity field, common threats, security principles, and tools used by security teams.

## What the course covered

- Cybersecurity and the work of an entry-level analyst
- The evolution of cyberattacks and different threat actors
- The eight CISSP security domains
- Security risks, frameworks, and controls
- The CIA triad and cybersecurity ethics
- SIEM tools, network protocol analysers, Linux, SQL, and Python
