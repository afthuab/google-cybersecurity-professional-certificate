# The Eight CISSP Security Domains

The CISSP Common Body of Knowledge is organised into eight domains. They cover different parts of information security and help show how security work fits together.

| Domain | Main focus | Example |
|---|---|---|
| 1. Security and Risk Management | Governance, policies, risk, and compliance | Setting an organisation's security policy |
| 2. Asset Security | Protecting information and other assets | Classifying customer records as confidential |
| 3. Security Architecture and Engineering | Designing secure systems | Using encryption to protect stored data |
| 4. Communication and Network Security | Protecting networks and communication | Using firewalls and network segmentation |
| 5. Identity and Access Management | Managing identities and permissions | Giving users only the access they need |
| 6. Security Assessment and Testing | Checking whether security controls work | Performing a vulnerability assessment |
| 7. Security Operations | Day-to-day security activities | Monitoring alerts and handling incidents |
| 8. Software Development Security | Building and maintaining secure software | Reviewing code and validating user input |

## Connection to SOC work

SOC analysts are closely involved in Security Operations. They also use knowledge from Network Security, Identity and Access Management, and Security Assessment and Testing when investigating alerts.

## Key point

The domains are connected. For example, an access-control weakness (Domain 5) may lead to an incident that the SOC investigates (Domain 7).
