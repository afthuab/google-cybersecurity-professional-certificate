# Cybersecurity Glossary

| Term | Meaning |
|---|---|
| Access control | Rules that decide who can use a resource. |
| Authentication | Checking that a user or system is who it claims to be. |
| Authorisation | Deciding what an authenticated user is allowed to do. |
| Availability | Keeping systems and information accessible when needed. |
| CIA triad | Confidentiality, Integrity, and Availability. |
| Data breach | Exposure or access to information without authorisation. |
| Defence in depth | Using several layers of security controls. |
| DoS | Denial-of-Service; an attempt to make a service unavailable. |
| DDoS | A DoS attack carried out using multiple systems. |
| Encryption | Converting readable data into a protected form. |
| Firewall | A control that filters network traffic according to rules. |
| Hash | A fixed-length output created from data by a hash function. |
| IDS | Intrusion Detection System. |
| Incident response | The process for handling and recovering from security incidents. |
| Least privilege | Giving users only the access they need. |
| Malware | Software designed to perform harmful or unauthorised actions. |
| MFA | Multi-Factor Authentication; using more than one type of proof to verify identity. |
| NIST | National Institute of Standards and Technology. |
| Phishing | A deceptive message designed to trick someone into taking an unsafe action. |
| Ransomware | Malware that blocks access to data or systems and demands payment. |
| Risk | The possibility of loss or harm when a threat affects a weakness. |
| SIEM | Security Information and Event Management. |
| SOC | Security Operations Centre. |
| Threat actor | A person or group that may carry out a cyberattack. |
| Vulnerability | A weakness that could be exploited. |
| VPN | Virtual Private Network. |
