# Course 3 – Network Security Glossary

| Term | Meaning |
|---|---|
| Access Control List (ACL) | A set of rules on a router or firewall that permits or denies traffic based on IP addresses, ports, and protocols |
| ARP | Address Resolution Protocol; resolves an IPv4 address to a physical MAC address on a local network |
| CIDR | Classless Inter-Domain Routing; represents subnet prefix length using slash notation (such as `/24`) |
| Cloud computing | On-demand delivery of computing, storage, and networking resources over the internet |
| DDoS | Distributed Denial of Service; an attack using many compromised systems to overwhelm a target with traffic |
| DHCP | Dynamic Host Configuration Protocol; automatically assigns IP addresses and network settings to devices |
| DMZ | Demilitarised Zone; a segmented perimeter subnet hosting public-facing services separate from the internal network |
| DNS | Domain Name System; translates human-readable domain names into IP addresses |
| Encapsulation | Wrapping data with protocol headers as it moves down the layers of a network model |
| Firewall | A network security control that monitors and filters traffic according to defined rules |
| IDS | Intrusion Detection System; monitors traffic or system activity and alerts on suspicious behaviour |
| IPS | Intrusion Prevention System; monitors traffic inline and actively blocks detected threats |
| IP spoofing | Forging the source IP address in packet headers to hide origin or impersonate a trusted system |
| MAC address | A 48-bit physical identifier assigned to a network interface for local network communication |
| NAT | Network Address Translation; maps private internal IP addresses to public IP addresses |
| NIST CSF | NIST Cybersecurity Framework; a framework for managing cybersecurity risk across core functions |
| On-path attack | An attack where an adversary intercepts and possibly alters communication between two parties |
| OSI model | A seven-layer conceptual model describing how data moves across a network |
| Packet sniffing | Capturing and inspecting network packets using tools such as `tcpdump` or Wireshark |
| Port | A logical endpoint number (`0–65535`) used by TCP and UDP to direct traffic to specific services |
| Proxy server | An intermediary server that forwards requests between clients and destination servers |
| Security hardening | Reducing attack surface by removing unnecessary services, applying patches, and tightening settings |
| SDN | Software-Defined Networking; separates the network control plane from the forwarding data plane |
| Subnetting | Dividing a larger IP network into smaller logical subnetworks |
| SYN flood | A DoS attack that sends rapid TCP `SYN` packets without completing handshakes |
| TCP/IP model | A four-layer networking model used for internet communication |
| VPN | Virtual Private Network; creates an encrypted tunnel across an untrusted network |
| WPA3 | Current Wi-Fi security standard providing stronger authentication and encryption |
