# Course 03 – Connect and Protect: Networks and Network Security

## Course overview

This course covers how computer networks operate, how data travels across local and cloud networks, and how security teams protect networks against common attacks. It introduces network architecture, protocols, subnetting, firewalls, VPNs, packet analysis, and system hardening.

## What I learned

- Explain how devices communicate using the TCP/IP and OSI models.
- Identify common network protocols, port numbers, and IPv4 subnet ranges.
- Understand how firewalls, VPNs, proxies, and security zones protect network boundaries.
- Recognise network intrusion tactics such as DoS/DDoS, sniffing, IP spoofing, and on-path attacks.
- Read basic `tcpdump` output to spot incomplete TCP handshakes and traffic anomalies.
- Describe operating system, network, and cloud hardening practices.
- Apply the NIST Cybersecurity Framework to structure a network incident response plan.

## Course modules

1. **Network architecture** – Network devices, cloud networks, SDN, TCP/IP and OSI models, and IP/MAC addressing.
2. **Network operations** – Common protocols and ports, CIDR subnetting, wireless security, firewalls, VPNs, proxies, and security zones.
3. **Secure against network intrusions** – DoS/DDoS attacks, reading `tcpdump` logs, packet sniffing, IP spoofing, and interception tactics.
4. **Security hardening** – Brute-force mitigation, OS and network hardening, IDS/IPS concepts, cloud network security, and NIST CSF incident response.
